## Tamamlayıcı CSS Laboratuvarı

[**01-css-tamamlayici.html**](./01-css-tamamlayici.html) dosyasında dört kısa deney yer alır. Dosyayı tarayıcıda açarak örnekleri çalıştırabilir, editörde açarak CSS yorumlarını okuyabilirsin.

| Deney | Neyi gözlemleyeceksin? |
| --- | --- |
| **01 · Birleşik seçiciler** | `.duyuru p` ile `.duyuru > p` arasındaki farkı ve `.etiket.acil` kuralının hangi durumda yazı rengini belirlediğini |
| **02 · Kutu genişliği** | Aynı `width: 200px` bildiriminin `content-box` ile 264 px, `border-box` ile 200 px genişliğinde bir kutu oluşturmasını |
| **03 · Esnek ölçüler** | `width: 100%` ve `max-width: 22rem` birlikte kullanıldığında kutunun dar ve geniş ekranlarda nasıl boyutlandığını |
| **04 · Fare ve klavye** | Fare bağlantının üzerindeyken `:hover`, Tab tuşuyla bağlantıya geldiğinde ise `:focus-visible` stilinin nasıl göründüğünü |

> [!TIP]
> Her örnekteki **Dene** yönergesini uygula. DevTools’ta bir CSS bildirimini kapatmadan önce sonucu tahmin et, ardından tarayıcıda neyin değiştiğini kontrol et.
