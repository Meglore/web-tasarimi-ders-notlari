## 🛠 Standartlar ve Geliştirme Kültürü

- **Versiyon Kontrolü:** Git & GitHub üzerinden dal/commit yönetimi.
- **Commit Standardı:** [Conventional Commits](https://www.conventionalcommits.org/) (`feat`, `docs`, `fix`, `refactor`, `chore`).
- **Hiyerarşi & Adlandırma:** Sunucu/URL uyumluluğu gözetilerek tüm dosya ve dizin yapısında katı `kebab-case` standardı uygulanır.
- **Dokümantasyon Dili:** GitHub Flavored Markdown (GFM), semantik veri tabloları ve erişilebilir çağrı blokları (`callouts`).
