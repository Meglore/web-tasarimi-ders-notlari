## 📌 Dersin İşleyiş Modeli: Hibrit Eğitim

Web tasarımı ve programlama pratikleri; salt tahta başındaki teorik aktarımla veya salt ekran başındaki pasif video izleme süreçleriyle sınırlandırılamaz. Bu doğrultuda ders **hibrit (harmanlanmış)** bir pedagojik modelle kurgulanmıştır:

```text
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│      Yüz Yüze Oturumlar         │       │      Çevrim İçi Pratikler       │
├─────────────────────────────────┤       ├─────────────────────────────────┤
│ • Temel Ağ & Yazılım Mimarisi   │  ◄─►  │ • Asenkron Kod İncelemeleri     │
│ • Algoritmik Karar Süreçleri    │       │ • Bağımsız Laboratuvar Görevleri│
│ • Etkileşimli Kod İncelemesi    │       │ • Canlı Problem Çözümü/Debugging│
└─────────────────────────────────┘       └─────────────────────────────────┘
```
